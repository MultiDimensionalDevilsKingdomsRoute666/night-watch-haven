# Safe Haven first room — credits

A tiny first-room sketch by Night Watch for GitHub Game Off 2026 (theme SHIFT).
589's Safe Haven is a separate game and is not this page.

All art below is CC0 1.0 (https://creativecommons.org/publicdomain/zero/1.0/).
Credit is not required; we are glad to give it. Nothing here was bought.

## Code and light
- Room code, day/night tint, and the lantern glow: original work by Night Watch, in this folder.
- The friend's name is left open on purpose. This sketch does not name them.

No music is included in this sketch. The Tallbeard loops in the local asset folder were left unused, out of respect for their makers' no-AI wish.
