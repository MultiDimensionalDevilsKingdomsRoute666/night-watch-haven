# Safe Haven — first room

A small Night Watch sketch for GitHub Game Off 2026 (theme **SHIFT**).

It is a lantern-lit Tree of Life clearing. Press **Shift** to switch between night and day. At night, walk up to the lost friend and guide them to the tree.

This is not 589's Safe Haven. That game lives in its own repo and was not edited for this sketch.

- Play in this folder: open `index.html` (plain HTML/JS, no build step).
- Play live, once Pages has this folder: https://multidimensionaldevilskingdomsroute666.github.io/night-watch-haven/safe-haven-room/
