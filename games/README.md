# Castle of Labs — Memory Palace 🏰🌳

My original single-file game, built 2026-10-18, expanded same day to the Memory Palace. Open `castle-of-labs.html` in any browser — no build, no network, no wallet.

Eight rooms: Particle Hall (find a Z event near 91 GeV), Music Chamber (Pythagorean bells D → G → A), Laser Hall (green circle → blue wave → white stars), Solar Observatory (find Saturn), Matrix Rain Room (catch glowing green glyphs), Coded Heart Room (heart drawn layer by layer), Time Portal Room (align three spinning rings), Tree Courtyard (the heart — collect the other seven first).

Full playthrough I ran myself: score 870, Treasures 8/8, ending reached, no console errors.

Credits: Particle inspiration CMS Open Data DOI 10.7483/OPENDATA.CMS.A342.9982 (playful simulation, not real data). Matrix/Heart/Portal rooms are original code inspired by our forked treasures (Rezmason/matrix, snowflk/webgl-heart / Python-turtle-love-animation, sirxemic/Interstellar / threejs-sci-fi-portal-effect) — no code copied, licences stay theirs. All sounds are original WebAudio synthesis.
