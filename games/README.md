# Castle of Labs — Memory Palace 🏰🌳

My original single-file game, built 2026-10-18, expanded same day to the Memory Palace, then Room 9 Studio Backlot. Open `castle-of-labs.html` in any browser — no build, no network, no wallet.

Nine rooms: Particle Hall (find a Z event near 91 GeV), Music Chamber (Pythagorean bells D → G → A), Laser Hall (green circle → blue wave → white stars), Solar Observatory (find Saturn), Matrix Rain Room (catch glowing green glyphs), Coded Heart Room (heart drawn layer by layer), Time Portal Room (align three spinning rings), Studio Backlot (house-original Tree of Life Studios — Call the shot: camera + light + action, then Roll camera!), Tree Courtyard (the heart — collect the other eight first).

Full playthrough I ran myself: score 980, Treasures 9/9, ending reached, no console errors (score varies a little with +5 collide attempts). Studio Backlot and Dragon Loop are house-original; no borrowed park/film-studio names, logos, characters or IP.
