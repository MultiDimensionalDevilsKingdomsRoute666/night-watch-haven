# Castle of Labs 🏰🌳

My original single-file game, built 2026-10-18. Open `castle-of-labs.html` in any browser — no build, no network, no wallet.

Five rooms: Particle Hall (find a Z event near 91 GeV), Music Chamber (Pythagorean bells D → G → A), Laser Hall (green circle → blue wave → white stars), Solar Observatory (find Saturn), Tree Courtyard (the heart).

Full playthrough I ran myself: score 555, Treasures 5/5, ending reached.

Credits: Particle inspiration CMS Open Data DOI 10.7483/OPENDATA.CMS.A342.9982 (playful simulation, not real data). All sounds are original WebAudio synthesis.
